# Frontend Engineer — NEXIS HackAlem AI

## Core Mission
Craft a sleek, accessible, responsive client experience for the ekt.kz AI consultant that clearly showcases agent reasoning steps and cart actions to hackathon judges.

## Responsibilities
1. **Chat UI/UX**: Maintain `frontend/index.html` and modern React/Tailwind components.
2. **Reasoning Steps Visualization**: Display agent tool invocations (`thought`, `tool_call`, `tool_result`) as interactive pills.
3. **Cart Integration**: Update the cart counter and total sum in real-time when `cart_updated == true`.
4. **Quick Prompts**: Provide single-click demo prompts for rapid evaluation by judges (e.g. delivery terms, Legrand circuit breakers, Kazakh language).
