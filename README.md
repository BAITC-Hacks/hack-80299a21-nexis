# NEXIS / ChipAI — консультант ekt.kz

Прототип для кейса №1 HackAlem AI 2026: чат помогает найти электротовары, проверить характеристики и наличие, сравнить доступные аналоги, разобрать спецификацию и собрать подтверждённый покупателем список закупки.

Frontend на TypeScript/Vite соединён с FastAPI API v2.1. Каталог читается из ekt.kz; корзина сохраняется в SQLite. Ошибка API показывается пользователю и не заменяется вымышленными товарами.

## Быстрый запуск: Docker

Нужен Docker Desktop с Linux containers. Команды выполняются из корня репозитория.

~~~powershell
if (!(Test-Path -LiteralPath .env)) { Copy-Item .env.example .env }
~~~

Заполните EKT_API_USER и EKT_API_PASS в .env. Существующий файл сохраните. Затем:

~~~powershell
docker compose up --build -d
~~~

- Приложение: http://localhost:5173
- Swagger: http://localhost:8000/docs
- Состояние: http://localhost:5173/api/health
- Остановка с сохранением корзин: docker compose down

Первый запуск загружает зависимости. Tesseract с русским, казахским и английским языками входит в backend-образ. SQLite находится в Docker volume. Подробности: [Docker и OCR](docs/docker-setup.md).

## Запуск на Windows без Docker

Нужны Python 3.14 и Node.js 24. Подготовьте .env, как показано выше. Первый запуск установит зависимости и запустит оба сервера:

~~~powershell
python backend/scripts/dev.py --install
~~~

В следующий раз:

~~~powershell
python backend/scripts/dev.py
~~~

Ctrl+C завершает оба сервера. Адреса: frontend http://localhost:5173, backend http://localhost:8000. Если порты заняты, остановите предыдущий запуск или задайте --api-port и --ui-port. Нативный режим требует отдельной установки Tesseract для фото и сканов; текстовые документы работают без него.

## Что умеет продукт

| Возможность | Реализация |
| --- | --- |
| Каталог | ID, артикул, название и нормализация обозначений; цена, склады, свойства, ссылки на документы и время проверки |
| Консультация | Приветствие, уточнение широкого запроса, контекст выбранного товара, количества, города и бюджета |
| Аналоги | Сравнение известных параметров, проверка наличия и объяснение совпадений; запрос более дешёвого варианта |
| Корзина | Серверные добавление, изменение количества и удаление; каждая операция требует отдельного подтверждения |
| Спецификации | Настоящая multipart-загрузка PDF, TXT, DOCX, XLSX, XLS, JPEG, PNG, WEBP; найденные и нераспознанные строки, частичная смета |
| Интерфейс | Адаптивный чат, карточки, маскот ChipAI, шаги выполненных действий, панель корзины и страница её актуального состояния |
| Языки | RU и KZ в консультации; интерфейс EN явно предупреждает, что ответы пока на русском |

Кнопки быстрых вопросов используют тот же API, что и обычные сообщения. Карточки сохраняют неизвестные цену и остаток, показывают предупреждения и ссылки на источники. Чат принимает текстовое подтверждение действующего предложения.

## Как устроен агент

Один AgentService совмещает программные правила и необязательный вызов модели через пять инструментов чтения: поиск, карточка, аналоги, условия покупки и склады города. Итоговые товарные факты формируются из полученных данных. Изменение корзины выполняет отдельный серверный сервис после проверки согласия.

OPENAI_API_KEY необязателен. Без ключа работают консультация по правилам и тот же живой каталог; при наличии ключа модель выбирает инструменты. В проверенном локальном окружении ключ отсутствует, поэтому реальный разговор с OpenAI пока не проверен.

Краткий контекст хранится в RAM до 30 минут, максимум 1024 сессии. После перезапуска он теряется; SQLite-корзина сохраняется. Архитектура: [docs/architecture.md](docs/architecture.md).

## Что пока ограничено

- API партнёра предоставляет чтение каталога. Корзина NEXIS — сохраняемый демонстрационный список: товар не резервируется, заказ на ekt.kz и платёж не создаются. Кнопка просмотра открывает этот список.
- Поиск охватывает настроенную выборку, по умолчанию 4 страницы, максимум 50. Числовой ID можно запросить напрямую. Полного индекса магазина нет.
- Аналоги проверяются для поддерживаемых категорий по доступным параметрам; неполные или противоречивые данные требуют уточнения.
- OCR читает маркировку. Определение точной модели по внешнему виду без текста не реализовано. Word .doc нужно преобразовать в .docx.
- Количества целочисленные; дробный метраж не поддерживается.
- Настоящие OpenAI-диалоги, работа под нагрузкой, CRM и размещение виджета на ekt.kz требуют отдельной проверки или доступа партнёра.
