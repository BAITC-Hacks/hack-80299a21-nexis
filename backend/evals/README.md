# Локальная оценка агента

```powershell
python -m backend.evals.run
python -m backend.evals.run --repeat 3 --output agent-eval-report.json
```

Запускать из корня репозитория после установки зависимостей backend.

`cases.py` содержит 72 сценария: 24 задачи на русском, казахском и английском.
Включены поиск точного артикула и штрихкода, характеристики и сертификат,
подбор аналога, город, количество, выбор второго варианта, уточнение параметров,
условия покупки, техническое объяснение и подтверждение корзины.

По умолчанию и в текущем runner внешние запросы отсутствуют: каталог заменён
тестовым транспортом, ключ модели очищается только внутри процесса оценки,
embeddings отключаются, базы корзины и знаний создаются во временной директории.
Платных вызовов нет. Локальная `.env` не изменяется.

Каждый сценарий проверяет язык ответа; числовые факты и ожидаемые действия
проверяются отдельными утверждениями. На каждом ходе без `cart_updated`
проверяется неизменность числа товаров в корзине. Дополнительные unit-тесты
`backend/tests/test_agent_v3.py` проверяют ошибки инструментов, таймауты,
инъекции через непроверенный ответ модели, сохранение результатов и контекст.

Отчёт сообщает результаты по языкам и время выполнения синтетических сценариев.
Это набор разработки и регрессий. Его результат **не является** оценкой качества
реальной LLM, независимой выборкой или измерением задержки живого API ekt.kz.
Перед заявлением о качестве нужно отдельно проверить реальные анонимизированные
вопросы, согласовать бюджет модельных вызовов и провести ревью казахских ответов.
