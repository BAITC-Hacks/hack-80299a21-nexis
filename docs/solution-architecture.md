# Соответствие решения кейсу ekt.kz

Этот документ описывает реализованный backend. Подробная схема — в [architecture.md](architecture.md), данные API — в [api-contract.md](api-contract.md).

| Требование | Реализация | Практическая граница |
| --- | --- | --- |
| Наличие и характеристики | GET карточки, цена, остаток, склады, свойства, время проверки | При сбое сообщает недоступность |
| Сертификат | Реальная ссылка из API | Отсутствующую ссылку не заменяет общим обещанием |
| Аналог отсутствующего товара | Проверка семейства, параметров и положительного остатка | При неполных данных/отсутствии подходящего кандидата честно сообщает об этом |
| Оплата, доставка, минимальная партия | Поиск по версионированным источникам и товарным свойствам | Спорные тарифы и индивидуальные условия — у менеджера |
| Добавление только после подтверждения | Единый CartService для HTTP и чата, одноразовый токен | Гостевая демонстрационная корзина |
| Количество в пределах остатка | Живой GET при записи, суммарное количество и транзакция | Не резервирует партнёрский склад |
| Прямая ссылка на корзину | HTML текущей SQLite корзины с токеном только чтения | Реальное оформление на ekt.kz ещё требует интеграции |
| Документы и изображения | PDF/TXT/DOCX/XLSX/XLS, OCR JPEG/PNG/WEBP | Tesseract устанавливается отдельно; .doc нужно преобразовать |
| Контекст сессии | Короткая история запроса и сохранённое предложение | История не сохраняется в БД; авторизация пользователя сайта не подключена |
| Казахский язык | language=kk, основные шаблоны/условия/подтверждение | Не все названия характеристик и ошибки переведены |
| Совместимость с frontend | CORS, источники, шаги, загрузка, API-контракт | UI ветка в этой работе не изменялась |

## Данные

Производственные ответы используют ekt.kz. Синтетические записи находятся в тестах и не подставляются в живые ответы. Цена и остаток зависят от момента проверки; BACKEND не сообщает, что уже оформил заказ.

Численные обещания экономии времени, роста конверсии и разгрузки менеджеров пока не подтверждены измерениями. На хакатоне демонстрируются рабочие сценарии и автоматические проверки, без выдуманных бизнес-метрик.

## Следующий шаг с партнёром

Получить официальный контракт изменения корзины и привязки сессии покупателя, полный поиск/выгрузку каталога, доверенные поля сертификатов и исправление противоречивых характеристик. CRM и запись заказа подключать только после получения соответствующих контрактов.
