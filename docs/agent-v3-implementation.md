## Уже проверено в этой итерации

Шесть новых проверок API прошли с синтетическим каталогом:

- английское подтверждение корзины, её HTML-страница и CSV;
- удаление на казахском при недоступном каталоге с обязательным подтверждением;
- статусы загрузки и количества на RU/KK/EN;
- сохранение числовых параметров ошибки недостаточного остатка;
- локализованная валидация без отражения присланных значений;
- неизменность исходных фактов товара и повторная локализация без потери предупреждения.

## Общие проверки после независимого разбора диалогов

- Полный backend после исправления сравнения: **160/160 тестов** на Windows, около 12 секунд.
- Frontend: **44/44**, TypeScript и production build; включён свежий коммит напарника bf2722b и исправление языка ссылок корзины e6b73e6.
- Диалоги: **72 сценария × 2 запуска = 144/144**, по 48 на RU/KK/EN. Это синтетический набор разработки, не оценка настоящей LLM.
- Поиск знаний: **30/30 Top-1 и Recall@5**, по 10 вопросов на язык. После исправлений этот набор является регрессионным, не независимым holdout.
- Живой API: smoke по товару 515291 успешен; цена/остаток проверены, конфликт характеристик сохранён; временная локальная корзина работает, записей партнёру нет. Один запуск занял 0,84 секунды; это не SLA.
- Импорт продолжился с сохранённой страницы 11, доведя локальный индекс до 220 товаров.

## Проверка собранного приложения

- `docker compose up --build -d`: оба сервиса работают, backend healthy, `/api/health` сообщает версию 3.0.0 и режим `rules`.
- В Linux-контейнере прошли **160/160 backend-тестов**. Tesseract содержит `rus`, `kaz`, `eng`; отдельный smoke распознал артикул и количество на сгенерированном изображении.
- В постоянный том Docker импортированы 11 страниц / 220 товаров. Индекс частичный, продолжение начинается со страницы 12.
- В браузере проверены ответы с источниками на RU/KK/EN; для отсутствующего термина ассистент сообщает недостаток подтверждённых данных.
- Живая карточка 515291 показывает цену, остаток, характеристики, время проверки и конфликт тока 160/250 А в данных партнёра. Уточнение `What is its voltage?` использует выбранный товар.
- `Compare products 515291 and 45357` проверен после исправления маршрутизации: обе карточки загружаются отдельно, таблица показывает фактические различия и неизвестные поля. Для позиции с нулевым остатком случайная замена не предлагается. Добавлены четыре backend-регрессии для RU/KK/EN, отсутствующих ID и недоступного API.
- Отмена предложения оставляет корзину пустой. Явное подтверждение добавляет 2 штуки в демонстрационную корзину; ссылка показывает ту же позицию и итог после перезапуска контейнера.
- После переключения на KZ ссылка на корзину содержит `language=kk`, её HTML-страница отображается на казахском. Ошибка старого языка ссылки исправлена и покрыта тремя регрессиями frontend.
- `docs/sample_specification.pdf` загружен через интерфейс: найдена одна позиция с количеством 2, неизвестная строка показана отдельно, итог помечен неполным, загрузка не изменяет корзину.
- В проверенном браузерном сеансе ошибок console не было. Дополнительно проверена область 390×844: ширина документа и его содержимого 375 px с учётом полосы прокрутки, виджет помещается в экран. Таблица сравнения прокручивается горизонтально, включая клавишу ArrowRight. Это проверка адаптивной вёрстки в настольном браузере; физическое мобильное устройство не проверялось.

Проверки относятся к локальной Docker-сборке и живому read-only API каталога. Заказ, резервирование и запись в системы партнёра не выполнялись.

## Внешние ограничения

- Для реального планировщика модели и векторизации нужен OPENAI_API_KEY. Локальная `.env` не заменялась, ключи в Git не добавлялись.
- Полный каталог ещё не импортирован; CLI готов продолжать по лимитам партнёра.
- Казахские переводы требуют вычитки носителем. Естественность и качество реальной модели на независимой выборке не измерены.
- Контекст диалога и ограничитель запросов остаются локальными одному процессу. Эксплуатационная нагрузка, несколько воркеров и публичное развёртывание требуют отдельной приёмки.
- Реальная корзина ekt.kz, резерв и CRM требуют официальных API партнёра.
