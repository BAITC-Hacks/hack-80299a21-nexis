# 🔌 Руководство по интеграции ИИ-консультанта в сайт ekt.kz

> Документ подготовлен для технических специалистов и веб-разработчиков ТОО «Электрокомплект».

---

## 1. Встраивание чат-виджета на сайт ekt.kz

Для добавления ИИ-консультанта на существующий сайт ekt.kz (1C-Битрикс / PHP / React / Vue) достаточно добавить один блок кода перед закрывающим тегом `</body>` в шаблоне сайта:

```html
<!-- NEXIS ekt.kz AI Consultant Widget -->
<script 
  src="https://cdn.ekt.kz/ai-assistant/widget.js" 
  data-api-url="https://ai.ekt.kz/api" 
  data-session-cookie="BITRIX_SM_SALE_UID"
  async>
</script>
```

### Как работает встраивание:
1. Скрипт автоматически создает плавающую кнопку ⚡ в правом нижнем углу страницы (`z-index: 9999`).
2. При клике открывается адаптивное окно чата, стилизованное под брендбук `ekt.kz`.
3. Виджет оптимизирован для десктопа и мобильных устройств (на экранах < 768px раскрывается на весь экран).

## 2. Архитектура передачи корзины (Cart Handover)

Поскольку прямое сохранение платежных данных в сторонних сервисах запрещено правилами безопасности и регламентом хакатона, интеграция корзины реализована через безопасный **Handover-механизм**:

### Вариант А: Прямой переход по ссылке (Реализован по умолчанию)
После явного подтверждения добавления товара («Да, добавь») ассистент выдает прямую ссылку:
```
https://ekt.kz/personal/cart/
```
Клиент переходит по ссылке, где видит добавленные позиции, привязанные к его сессии.

### Вариант Б: Серверный Webhook в корзину 1C-Битрикс
Бэкенд ассистента может вызывать внутренний API-метод интернет-магазина ekt.kz:
```http
POST https://ekt.kz/api/internal/cart/add
Content-Type: application/json
Authorization: Bearer <INTERNAL_EKT_TOKEN>

{
  "user_session_id": "sess_8921a91",
  "product_id": 515291,
  "quantity": 1
}
```

## 3. Эскалация обращений в CRM / WhatsApp менеджеров

Если клиент запрашивает связь со специалистом или просит индивидуальный расчет:
1. Агент собирает контакты (телефон / email / имя).
2. Вызывает эндпоинт `POST /api/manager/escalate`.
3. Сервер формирует лид в CRM ekt.kz (Bitrix24) с прикрепленной историей переписки:
   - Имя клиента
   - Телефон
   - Товары, которыми интересовался клиент
   - Полная стенограмма диалога
4. Клиент получает номер тикета и ссылку на прямой диалог в WhatsApp с дежурным инженером ekt.kz.
