# Источники базы знаний ekt.kz

Актуальная реализация — backend/knowledge_base.py. Проверено по публичным страницам 23 сентября 2026. Статьи содержат source_url, verified_at и verification_status; поиск без совпадения возвращает пустой результат.

| Тема | Источник | Что сообщает backend |
| --- | --- | --- |
| Оплата и доставка | [Условия покупки](https://ekt.kz/checkout-delivery/) | Способы оплаты, согласование доставки и самовывоз |
| Минимальная партия | [API каталога](https://ekt.kz/api/products) | Поля конкретного товара, без универсального обещания «от 1 шт.» |
| Сертификаты | Карточка товара из API | Только фактическая ссылка; иначе запрос документа у менеджера |
| Менеджер/филиал | [Контакты](https://ekt.kz/about/contacts/) | Ссылка на официальный справочник; без обещания передачи в CRM |
| Регистрация | [Информация покупателям](https://ekt.kz/about/information/) | Личный кабинет и выбор типа клиента |

На странице доставки обнаружены разные пороги бесплатной доставки. Backend не выбирает один из них как гарантированный тариф; уточнение передаётся менеджеру.

Не подтверждённые источниками ставки НДС, рассрочки, точные сроки возврата, автоматические счета/ЭСФ и придуманные телефоны не входят в ответы. Это не юридическая база: индивидуальные условия уточняются у партнёра.

## Retrieval и обновление

Сейчас используется небольшой корпус и поиск по словарю тем. Векторной БД и обучения на диалогах нет. Корпус подходит для демонстрационной выборки правил. После изменения партнёром условий нужно обновить содержание, ссылку, дату и приёмочные проверки.

Товарная информация берётся отдельно из API, со временем проверки и TTL. Общая статья про сертификаты не подтверждает наличие сертификата у каждого товара.
