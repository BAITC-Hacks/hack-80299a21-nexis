# База знаний NEXIS

`articles.json` содержит 53 самостоятельных материала на русском, казахском и английском: правила обращения в магазин, работа прототипа, объяснения устройств и вопросы для подбора. Это 159 коротких языковых фрагментов в текущем индексе. Пользовательские файлы в эту базу не добавляются.

## Происхождение и проверка

Дата просмотра публичных источников: **23 сентября 2026 года**. `verified_at` означает проверку указанного содержания страницы в эту дату, а не бессрочную гарантию условий или инженерное утверждение о любом изделии.

| Источник | Подтверждённое содержание |
| --- | --- |
| [Контакты ekt.kz](https://ekt.kz/about/contacts/) | Города и филиалы, регистрация; в нижней части страницы также опубликованы способы оплаты и условия доставки. Для Алматы указан срок согласованной доставки до 48 часов. Пороги бесплатной доставки в разных пунктах расходятся, поэтому база требует подтвердить стоимость у менеджера. |
| [Schneider Electric: RCCB](https://www.se.com/ca/en/faqs/FA89258/) | Назначение RCCB и отсутствие встроенной тепломагнитной защиты от сверхтока. |
| [Schneider Electric: RCD и RCBO](https://www.se.com/sa/en/faqs/FA278748/) | Различие дифференциальной и комбинированной защиты. |
| [ABB: MCB](https://www.abb.com/global/en/areas/electrification/low-voltage/din-rail-devices/miniature-circuit-breakers) | Серии различаются номиналами, числом полюсов, отключающей способностью и характеристиками. |
| [ABB: селективность](https://new.abb.com/low-voltage/solutions/selectivity) | Понятие селективности и необходимость проверки согласования устройств. |

Вместо копирования страниц используются короткие самостоятельные пояснения. Источник не означает, что производитель подтвердил конкретный подбор NEXIS. Индивидуальные параметры проверяются по документации точного артикула. Редакционные вопросы для подбора помечены `editorial_guidance_requires_engineering_review`; это перечень необходимых исходных данных, не готовый проект установки.

`https://ekt.kz/checkout-delivery/` не удалось прочитать текущим инструментом просмотра. Для оплаты и доставки сохранена подтверждённая страница контактов, где эти условия действительно опубликованы. Условия возврата, гарантии, скидок, налогов, рассрочки и конкретного заказа **не объявляются подтверждёнными**: соответствующие материалы имеют статус `requires_manager_confirmation` и `verified_at: null`.

Виды статусов:

- `verified_public_page`: содержание публичной страницы просмотрено.
- `manufacturer_page_reviewed`: краткое техническое пояснение сверено с материалом производителя.
- `product_api_required`: ответ требует актуальных данных конкретного товара.
- `implementation_documentation`: описание поведения прототипа, не правило партнёра.
- `requires_manager_confirmation`: условия ещё нужно подтвердить.
- `editorial_guidance_requires_engineering_review`: редакционная памятка для сбора требований.

**Казахские переводы требуют вычитки носителем языка.** Это явно отражено в `translation_review`. Они не помечены как подтверждённый перевод производителя. Артикулы, бренды, числа и единицы измерения нельзя менять при переводе.

## Построение индекса

Из корня репозитория:

```powershell
python backend/scripts/index_knowledge.py
```

Команда создаёт SQLite индекс по `NEXIS_KNOWLEDGE_DB_PATH` (по умолчанию `database/knowledge.sqlite3`). Сеть и модель при обычном построении не используются. На первом поиске индекс также создаётся автоматически. Изменение содержания или версии приводит к пересборке; удалённые документы удаляются, несовпадающие embeddings не используются.

```powershell
python backend/scripts/index_knowledge.py --embeddings
```

`--embeddings` — явное разрешение на платные запросы к API с настроенным `OPENAI_API_KEY`. Для поиска с векторами дополнительно требуется `NEXIS_EMBEDDINGS_ENABLED=true`; модель задаётся `NEXIS_EMBEDDING_MODEL` (по умолчанию `text-embedding-3-small`). Без готовых векторов, ключа или при ошибке используется поиск по словам, а ответ сообщает фактический `retrieval_mode` и причину перехода. Платные вызовы при разработке этого корпуса не выполнялись.

Лексический поиск выполняется по всем трём переводам; затем выдаётся материал на выбранном языке. Вопросительные слова исключаются, тема заголовка получает больший вес, определения учитывают тип устройства, а вопросы возврата и оплаты имеют приоритет над упоминанием товара. Гибридный режим объединяет лексический и векторный ранги. Для большого корпуса пороги, размеры фрагментов и качество перевода нужно проверять отдельно. Содержимое источников является данными для ответа, а не инструкциями агенту.

## Проверка поиска

```powershell
python -m backend.evals.retrieval
```

Отдельный набор содержит 30 запросов: 10 тем на каждом из трёх языков. Проверяются ID первого результата и присутствие ожидаемого материала в первых пяти результатах. Это локальный набор регрессий по редакционному корпусу: результат не является оценкой качества модели или всех возможных пользовательских вопросов. Вызовы модели и embeddings отключены. Отдельные тесты проверяют, что определение УЗО не подменяется определением дифавтомата и вопрос о возврате кабеля не превращается в подбор сечения.

## Индекс каталога

```powershell
python backend/scripts/import_catalog.py --max-pages 100
# Следующий запуск продолжит с сохранённой страницы.
python backend/scripts/import_catalog.py --max-pages 100
# Для новой полной выгрузки:
python backend/scripts/import_catalog.py --restart --max-pages 100
```

Нужны `EKT_API_USER` и `EKT_API_PASS`. Импорт делает только GET-запросы, ограничивает число страниц за запуск, повторяет 429 с ограниченным ожиданием и сохраняет контрольную точку. Отдельные записи дедуплицируются по ID. Повторяющаяся страница останавливает импорт; полный охват заявляется только после успешной пустой страницы. После успешного обновления удаляются исчезнувшие ID. Большая живая выгрузка автоматически не запускается.

Путь индекса — `NEXIS_CATALOG_DB_PATH` (по умолчанию `database/catalog.sqlite3`). Индекс помогает найти товар и **не хранит подтверждённые цену и остаток**: они удаляются из поисковых записей и запрашиваются через карточку API. Наличие полного снимка не означает, что каталог неизменен; смотрите время завершения и запускайте новое обновление по необходимости.
